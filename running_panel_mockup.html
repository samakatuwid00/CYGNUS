Status system

Rules

  • Status is always icon + word + colour, so it reads without colour.
  • "Needs you" (confirm, waiting agent, stuck) pins to the top with its buttons inline.
  • Groups are collapsible and show counts; Apps collapse past 5 with "+ N more".
  • Sort inside a group: needs you, stuck, working, running, idle, then name.
  • Buttons have three kinds: secondary (default), primary (green confirm), danger (red stop).
  • Stopping confirms inline and names the program and port before anything happens.
  • The count pill counts things that are active (working + needs you), same as the Panels badge.
  • Spacing uses 4 / 8 / 12 / 16 only.
